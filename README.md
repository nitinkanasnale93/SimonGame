## 🎯 About the Game

Simon Memory Game is a browser-based game that challenges you to remember and repeat an increasingly long sequence of coloured buttons.

Each round adds another colour. Remember the pattern, repeat it correctly, and see how far you can go!

## ✨ Features

- **Start & Restart** — begin a new game or play again after losing.
- **Random Colour Sequences** — a new colour is added each round.
- **Visual Feedback** — watch the buttons flash and respond to your clicks.
- **Increasing Difficulty** — each successful round extends the sequence.
- **Game Over Detection** — an incorrect colour ends the game.
- **Responsive Design** — play on desktop or smaller screens.

## 🕹️ How to Play

1. Open the [live game](https://simongame-ji84.onrender.com/).
2. Click **Start Game**.
3. Watch the sequence of flashing colours.
4. Repeat the colours in exactly the same order.
5. Complete the sequence to advance to the next level.
6. Make a mistake? Start again and beat your previous level.

## 💻 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/nitinkanasnale93/SimonGame.git
```

**2. Open the project folder**

```bash
cd SimonGame
```

**3. Run the game**

Open `index.html` in your browser, or use the Live Server extension in VS Code.

No additional packages or build commands are required.
