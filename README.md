## About the Project

Simon Memory Game is a browser-based game that challenges players to remember and repeat an increasingly long sequence of coloured buttons.

Each round adds a new colour to the sequence. One wrong selection ends the round, and the player can restart to try again.

## Features

- **Start and Restart** — begin a new game or try again after losing.
- **Random Sequences** — a new colour is added in every round.
- **Visual Feedback** — buttons flash to show the sequence and register player input.
- **Progressive Difficulty** — each successful round increases the sequence length.
- **Game Over Detection** — incorrect selections end the current game.
- **Responsive Layout** — the interface adjusts for smaller screens.

## How to Play

1. Click **Start Game**.
2. Watch the coloured buttons flash in sequence.
3. Repeat the sequence by clicking the same colours in the same order.
4. Complete the sequence to advance to the next level.
5. Make a mistake? Click **Play Again** to restart.

## Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/nitinkanasnale93/SimonGame.git
```

**2. Open the project folder**

```bash
cd SimonGame
```

**3. Launch the game**

Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.

No package installation or build command is required.
